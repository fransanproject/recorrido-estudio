# Estudio de recorridos — online

Del vídeo del recorrido a la web inmersiva, todo en el navegador.

**Usar:** abre la página, sube el vídeo, marca cada habitación, genera y descarga el ZIP.

- El vídeo **no se sube a ningún servidor**: se procesa en tu dispositivo.
- El ZIP contiene una web estática (`index.html` + `recorrido.mp4` + fotos):
  súbelo a Netlify, Vercel o GitHub Pages y comparte el enlace.
- En la web generada, el scroll va cosido al vídeo: avanza entre habitaciones
  y se congela en la fotografía de cada estancia marcada.

**Consejo de grabación:** un solo plano continuo, sin cortes, velocidad constante.
